feat: Introduz uma nova funcionalidade ou recurso ao código

fix: Corrige um bug ou problema existente no sistema

refactor: Modifica o código de produção para melhorá-lo internamente (ex: legibilidade, performance), sem alterar o comportamento do usuário (não adiciona recurso nem corrige bug)

test: Adiciona, altera ou remove testes unitários, de integração ou automatizados (sem mexer nas regras de negócio)

docs: Modifica apenas arquivos de documentação (como README.md, wikis ou comentários de código)

chore: Atualizações de tarefas rotineiras, ferramentas ou build, que não alteram o código de produção nem arquivos de teste (ex: atualizar pacotes no package.json, configurações de linters ou CI/CD)
